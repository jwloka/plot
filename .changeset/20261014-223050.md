A slice line may name the commits that completed it, so a plan whose slices were pushed straight to the default branch can be delivered: `→ commit abc1234`, several as `→ commit abc1234, def5678`, another repository as `→ owner/repo@abc1234`. `plot-plan-meta.sh` reports them as `waves[].branches[].commits`. `/plot-deliver` fetches the default branch and counts the slice done once every named commit is reachable from `origin/<default>`; one commit that is not there keeps it open, and the commits decide the slice whatever a PR of the same name says. `plot-fleet-scan.sh` reads the same commits as evidence for wave eligibility. A commit in another repository cannot be read from here, so that slice stays open and the refusal names the limit. Existing `→ #N` slices read as before.
