## New defects

1. **The D20 slice makes the Jira open read instance-wide where no `Ticket prefixes` is declared.** Must change. Plan `:69` and `:158` drop `assignee = currentUser()` and "keep the project scope", but the scope is empty when the key is undeclared: `plot-host.sh:4674-4684` splices `$scope` only when `tracker_projects` answers, and `plot-host.sh:2504-2507` keeps the undeclared case unscoped on purpose. The person clause is then the only thing that keeps the read off other customers' tickets, which is the measured incident at `plot-host.sh:2480-2484`. After the slice the read is `resolution = EMPTY ORDER BY created DESC` over the whole instance, up to 1000 rows per pass, into the index and onto every reader's lanes. The plan requires `Ticket prefixes` for the closed read (`:54`) and not for the open read. The slice must state what the open read does with no prefixes: keep the assignee clause, or exit 4 with a reason as the closed read does. `skills/plot-board-setup/SKILL.md:229-231`, `skills/plot-init/SKILL.md:205-208` and `plot-config.sh:180-183` describe the undeclared key as "keeps the instance-wide query" and need the same sentence.
2. **The D20 slice widens *Waiting on you* for an unmatched Jira reader, and the plan says it does not.** Must change. D22 shows every ticket to a reader with no match, and today no `People` entry carries a `jira:` spelling, because the grammar is new (`the-board-has-three-tabs.md:47`, `:72`). So on every Jira repository at upgrade the inbox goes from the reader's own tickets to the whole project, with a notice. Changelog `:20` ("keeps showing only your tickets"), Acceptance `:130` ("still shows only the reader's Jira tickets") and Open Point `:106` ("the Delivery inbox never widens before its filter exists") are true only for a reader whose handle has a `jira:` spelling. The plan must state the widening and the notice, or hold the clause until the reader matches. For the operator: the machine already knows the Jira identity that `currentUser()` resolves to, `JIRA_EMAIL` (`plot-host.sh:2616`, `:2635`), so a match that reads it needs no `People` entry; D21 chose `People`, and this is an estate fact for the sibling, not a change this plan can make alone.
3. **The Archived lane hard-codes `docs/stories/archived/`.** Must change. The board reads the story home from the `Story directory` key with `docs/stories/` as the default (`board.ts:1846`, `:1873`, `:2734`; `server/story.ts:95`), and the story-tracking skill archives into `<home>/archived/` for any home (`skills/story-tracking/SKILL.md:141-150`). 4. **The cost figures do not match the host.** Open point. Measured 2026-10-12: 154 issues closed since 2026-09-28, so one pass reads 2 open pages and 2 closed pages, not 1 closed page (plan `:63`).
